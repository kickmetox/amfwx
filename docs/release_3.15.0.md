# AMFWX 3.15.0

AMFWX 3.15 adds MCP support.

## New

- `MCPClient`
- `MCPServer`
- stdio JSON-RPC
- `python -m amfwx.mcp`
- UI tools exposed via `tools/list` and `tools/call`
- 201 tests

## Assets

- `amfwx-3.15.0-py3-none-any.whl`
- `AMFWX-Portable-3.15.0.zip`
- `AMFWX-Own-Setup-3.15.0.exe` (unsigned)
- `SHA256SUMS.txt`

## Notes

- stdio transport only
- no auth
- Windows-only
- unsigned installer
