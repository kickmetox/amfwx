# AMFWX 3.9.0

AMFWX 3.9 adds the Tkinter compatibility adapter.

## New

- `amfwx.compat.tkinter`
- `Tk`, `Frame`, `Label`, `Button`, `Entry`, `Checkbutton`
- `StringVar`, `IntVar`, `DoubleVar`, `BooleanVar`
- `pack`, `grid`, `place`
- `messagebox`
- 189 tests

## Assets

- `amfwx-3.9.0-py3-none-any.whl`
- `AMFWX-Portable-3.9.0.zip`
- `AMFWX-Own-Setup-3.9.0.exe` (unsigned)
- `SHA256SUMS.txt`

## Notes

- AMFWX-native interpretation, not Tcl/Tk
- no ttk themes/Treeview/Notebook
- Windows-only
- unsigned installer
