# AMFWX 3.44.0

AMFWX 3.44 extends WIA acquisition with settings and multi-page support.

## New

- DPI
- color mode
- duplex flag
- ADF/multi-item loop
- `acquire_pages`
- 261 tests

## Notes

- ADF support depends on the driver exposing multiple WIA items
- TWAIN image transfer still not implemented
- Windows-only
- unsigned installer
