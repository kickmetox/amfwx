# AMFWX 3.30.0

AMFWX 3.30 adds Modbus RTU.

## New

- `ModbusRTU`
- CRC16
- read coils
- read holding registers
- write single/multiple registers
- optional transport for tests
- 235 tests

- `amfwx-3.30.0-py3-none-any.whl`

- `SHA256SUMS.txt`

- no Modbus ASCII yet

- unsigned installer
