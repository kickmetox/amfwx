# AMFWX 3.55.0

AMFWX 3.55 wires the demo app through the new lifecycle.

## New

- CLI options through `Application`
- crash logger installed at startup
- demo window factory
- 275 tests

## Usage

```powershell
python -m amfwx --version
python -m amfwx --theme light
python -m amfwx --no-single
```
