# AMFWX 3.12.0

AMFWX 3.12 adds the JUCE compatibility adapter.

## New

- `amfwx.compat.juce`
- `Component`, `DocumentWindow`, `ResizableWindow`
- `Label`, `TextButton`, `TextEditor`
- `Slider`, `ComboBox`, `ToggleButton`
- `Colour`
- 195 tests

## Assets

- `amfwx-3.12.0-py3-none-any.whl`
- `AMFWX-Portable-3.12.0.zip`
- `AMFWX-Own-Setup-3.12.0.exe` (unsigned)
- `SHA256SUMS.txt`

## Notes

- AMFWX-native interpretation, not JUCE
- no audio/MIDI engine
- no plugin host
- Windows-only
- unsigned installer
