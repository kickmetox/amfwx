# AMFWX 3.2.0

AMFWX 3.2 adds PDF export and AMFW bridge tests.

## New

- `Canvas.save_pdf`
- `Window.render_to_pdf`
- single-page PDF with lossless RGB/Flate image
- AMFW bridge integration tests (skipped without AMFW)
- 171 tests

## Assets

- `amfwx-3.2.0-py3-none-any.whl`
- `AMFWX-Portable-3.2.0.zip`
- `AMFWX-Own-Setup-3.2.0.exe` (unsigned)
- `SHA256SUMS.txt`

## Notes

- Windows-only
- unsigned installer; signing is not part of the project
- PDF text is rasterized, not vector text
- one page per canvas
