# AMFWX 3.71.0

AMFWX 3.71 adds home-automation adapters and discovery.

## Real clients

- Shelly Gen1/Gen2/Gen3 (cover, light, TRV)
- Fibaro Home Center
- Jarolift MQTT bridge
- WLAN netsh

## Generic

- `GenericHttpDevice` for Becker, HomePilot, TaHoma, Eve bridge, seve

## Discovery

- mDNS/Bonjour
- SSDP
- HTTP fingerprints: Shelly, Fibaro, Tasmota, Reolink, HomePilot, TaHoma
- FRITZ!Box host list
- KNXnet/IP search
- Tuya broadcast detection

## Not implemented

- Becker native API
- HomePilot native API
- TaHoma OAuth
- Matter/Thread commissioning
- Tuya LAN AES
- Zigbee2MQTT subscriptions
- Reolink control

312 tests.
