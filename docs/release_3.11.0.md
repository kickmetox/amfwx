# AMFWX 3.11.0

AMFWX 3.11 adds the GTK compatibility adapter.

## New

- `amfwx.compat.gtk`
- `Application`, `ApplicationWindow`
- `Box`, `Grid`
- `Label`, `Button`, `Entry`, `CheckButton`, `Switch`
- `Scale`, `ProgressBar`, `Separator`, `HeaderBar`
- 193 tests

## Assets

- `amfwx-3.11.0-py3-none-any.whl`
- `AMFWX-Portable-3.11.0.zip`
- `AMFWX-Own-Setup-3.11.0.exe` (unsigned)
- `SHA256SUMS.txt`

## Notes

- AMFWX-native interpretation, not GTK
- no CSS/GTK templates
- Windows-only
- unsigned installer
