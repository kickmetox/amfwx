# AMFWX 3.38.0

AMFWX 3.38 adds hardware diagnostics.

## New

- `tools/hardware_check.py`
- JSON report for serial/HID/USB/Bluetooth/WLAN/displays
- backend availability for PCAN and OPC UA
- CI hardware report
- 250 tests

## Notes

- FireWire remains unsupported
- report is diagnostic, not a certification
- Windows-only
- unsigned installer
