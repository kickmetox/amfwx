# AMFWX 3.37.0

AMFWX 3.37 adds a unified device inventory.

## New

- `list_devices`
- `DeviceManager`
- serial/HID/USB/Bluetooth/WLAN/displays in one snapshot
- 249 tests

## Notes

- Bluetooth is known/remembered devices only
- raw USB only WinUSB-bound devices
- displays are monitors, not connectors
- Windows-only
- unsigned installer
