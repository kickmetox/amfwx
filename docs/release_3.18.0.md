# AMFWX 3.18.0

AMFWX 3.18 adds an accessibility audit and screenreader checklist.

## New

- roles for `RadioButton`, `SpinBox`, `ListBox`, `ProgressBar`
- `tools/a11y_audit.py`
- audit in CI
- screenreader checklist
- 208 tests

## Assets

- `amfwx-3.18.0-py3-none-any.whl`
- `AMFWX-Portable-3.18.0.zip`
- `AMFWX-Own-Setup-3.18.0.exe` (unsigned)
- `SHA256SUMS.txt`

## Notes

- audit is not a formal certification
- manual NVDA/Narrator checks remain required
- Windows-only
- unsigned installer
