# AMFWX 3.70.0

AMFWX 3.70 adds remote/IoT clients.

## New

- `FritzBox` (TR-064 login, hosts, WLAN)
- `DeconzClient` (Zigbee/deCONZ REST)
- `TuyaCloud` (signed cloud API)
- `WlanController` (netsh)
- 303 tests

## Limits

- no Tuya LAN protocol
- no Zigbee2MQTT/MQTT
- no FRITZ!Box smart-home switches
- Bluetooth is inventory only
