# AMFWX 3.10.0

AMFWX 3.10 adds the wxWidgets compatibility adapter.

## New

- `amfwx.compat.wx`
- `App`, `Frame`, `Panel`, `BoxSizer`
- `StaticText`, `Button`, `TextCtrl`, `CheckBox`, `Gauge`, `Choice`
- `Menu`, `MenuBar`, `StatusBar`
- `Bind`
- 191 tests

## Assets

- `amfwx-3.10.0-py3-none-any.whl`
- `AMFWX-Portable-3.10.0.zip`
- `AMFWX-Own-Setup-3.10.0.exe` (unsigned)
- `SHA256SUMS.txt`

## Notes

- AMFWX-native interpretation, not native wx controls
- simple box sizers only
- Windows-only
- unsigned installer
