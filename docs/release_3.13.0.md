# AMFWX 3.13.0

AMFWX 3.13 adds the Qt/PySide compatibility adapter.

## New

- `amfwx.compat.qt`
- `QApplication`, `QMainWindow`, `QWidget`
- `QVBoxLayout`, `QHBoxLayout`
- `QLabel`, `QPushButton`, `QLineEdit`, `QCheckBox`
- `QSlider`, `QComboBox`, `QProgressBar`, `QTextEdit`
- `clicked` signal
- 197 tests

## Assets

- `amfwx-3.13.0-py3-none-any.whl`
- `AMFWX-Portable-3.13.0.zip`
- `AMFWX-Own-Setup-3.13.0.exe` (unsigned)
- `SHA256SUMS.txt`

## Notes

- AMFWX-native interpretation, not Qt
- no QML/stylesheets
- Windows-only
- unsigned installer
