# S7comm

**Experimental.** The protocol is implemented at packet level and is not
certified against every S7 CPU.

```python
from amfwx import S7Client

with S7Client("192.168.0.10") as plc:
    data = plc.read_db(db=1, start=0, size=4)
    plc.write_db(db=1, start=0, data=b"\x01\x02\x03\x04")
```

## Implemented

- ISO-on-TCP / COTP connection
- S7 setup communication
- read DB / Merker / input / output
- write DB / Merker / input / output
- TPKT framing

## Not implemented

- S7-1200/1500 optimized block access
- symbolic addressing
- multi-variable requests
- PLC stop/start
- diagnostics
- security/authentication
- S7 routing
- hardware-tested validation

## Warning

S7 variants differ. Test read/write on a non-production PLC first.
Wrong addresses or DB numbers can disturb a running controller.

## Limits

- Windows-only (TCP itself is portable)
- no hardware-in-the-loop CI
- no vendor certification
